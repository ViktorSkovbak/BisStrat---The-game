## Prompt
Name three reasons an activity can have high leverage and give one example of each from a 15-person hardware startup. Then name one activity that looks productive but has low leverage.

## Model answer
Per Grove (via summaries): the action reaches many people (a clear weekly priority list), a short action changes someone's work for a long time (teaching a new engineer how to scope a test), or one piece of information shapes a group's work (telling the team which pilot customer decides the quarter). Low leverage: doing a task yourself that a team member could do, such as writing production code while three people wait for a spec. Leverage also saturates: once priorities are clear, the next hour there adds little.

## Grading notes
Needs the three sources (breadth, duration, key information), a startup-specific example for each, and a sensible low-leverage example. Add a point for noting that returns diminish. Generic lists of "good management habits" score 1-2.
