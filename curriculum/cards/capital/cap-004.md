## Prompt
Name the main uses of a company's cash, say what single test each must pass, and explain what Henry Singleton's buybacks at Teledyne illustrate. Apply it to your own company: when would you return cash instead of investing it?

## Model answer
Uses (Thorndike's framework, from secondary summaries: not yet verified): invest in the business, acquire, repay debt, buy back stock, pay dividends. Each is judged by the same test: does it earn more than the cost of capital, and more than the next-best use? Singleton bought back about 90% of Teledyne's shares between 1972 and 1984 (figure from summaries: not yet verified) because, with his shares cheap and acquisitions dear, buying his own stock beat the alternatives. For a young hardware company: return cash only if no line clears the cost of capital, which is rare in the first years; the discipline instead is to release growth money only against a rising return path.

## Grading notes
Full marks need one common hurdle across all uses, a link from Singleton to "best use of cash wins", and a concrete rule for the new company. Listing the options without the test is a 2.
