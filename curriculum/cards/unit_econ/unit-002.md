## Prompt
You need to cut unit cost 4× and have one push to fund: triple the monthly volume, or redesign for manufacture so that cost falls 20% per doubling instead of 15%. Which gets you to target cost sooner, roughly by how much, and why?

## Model answer
Redesign wins. Tripling volume builds the same roughly 370 units, only 3× faster. At 80% instead of 85% the units needed fall to about 74, which is about 5× fewer. The learning rate sits in the exponent; volume only changes the speed of the clock. Volume still helps cash, but it does not lower the number of units you must build. Caveat: the redesign must really deliver those points, so test it early.

## Grading notes
Full marks need: redesign is faster by about 5× versus about 3×, and the reason (units needed versus speed). A pure "volume gives scale" answer without the units logic is a 1-2. Note the caveat on the assumption for the top grade.
